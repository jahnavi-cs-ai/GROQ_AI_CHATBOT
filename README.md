# 🤖 GROQ AI Chatbot

A modern, fast, and responsive AI chatbot built using **Streamlit** and the **Groq API**. The application provides an elegant dark-themed interface with support for multiple Llama models, adjustable AI parameters, and a smooth conversational experience.

---

## ✨ Features

- 🎨 Modern responsive UI
- 🌙 Beautiful dark theme
- 🤖 Powered by Groq LLMs
- ⚡ Ultra-fast inference
- 💬 Chat history
- 🔄 Clear chat option
- 🎛️ Adjustable Temperature
- 📏 Adjustable Max Tokens
- 📱 Mobile-friendly interface
- 🧠 Supports multiple Llama models

---

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/GROQ-AI-Chatbot.git
cd GROQ-AI-Chatbot
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Environment

Windows

```bash
.venv\Scripts\activate
```

Mac/Linux

```bash
source .venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Setup Environment Variable

Create a `.env` file in the project directory.

```env
GROQ_API_KEY=your_groq_api_key
```

---

## ▶ Run the Application

```bash
streamlit run app.py
```
